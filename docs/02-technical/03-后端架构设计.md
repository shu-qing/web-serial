# 后端架构设计

> 文档版本：1.0.0  
> 最后更新：2024-01-XX  
> 负责人：后端架构师

## 1. 技术栈

- **运行时**: Node.js 18 LTS
- **框架**: Express.js
- **WebSocket**: ws
- **数据库**: PostgreSQL + Prisma ORM
- **缓存**: Redis
- **认证**: JWT

## 2. 分层架构

```
Controllers → Services → Repositories → Database
     ↓           ↓            ↓
  REST API   业务逻辑     数据访问
```

## 3. 目录结构

```
src/
├── controllers/
│   ├── authController.ts
│   ├── profileController.ts
│   ├── macroController.ts
│   └── sessionController.ts
├── services/
│   ├── userService.ts
│   ├── profileService.ts
│   └── sessionService.ts
├── repositories/
├── models/
├── middleware/
│   ├── authMiddleware.ts
│   └── errorHandler.ts
├── websocket/
└── server.ts
```
