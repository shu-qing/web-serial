## 1. 架构概览

### 1.1 技术栈

- **框架**: React 18 + TypeScript
- **状态管理**: Zustand
- **路由**: React Router v6
- **UI**: Tailwind CSS + Headless UI
- **构建**: Vite
- **HTTP**: Axios

## 3. 状态管理设计

### 3.1 串口状态管理

```typescript
// stores/useSerialStore.ts
interface SerialState {
  // 连接状态
  port: SerialPort | null
  isConnected: boolean
  config: SerialConfig
  
  // 数据
  receiveBuffer: LogEntry[]
  sendHistory: string[]
  
  // 统计
  stats: {
    rxBytes: number
    txBytes: number
    rxRate: number
  }
  
  // Actions
  connect: (config: SerialConfig) => Promise<void>
  disconnect: () => Promise<void>
  send: (data: string) => Promise<void>
  clear: () => void
}
```

---

### 3.2 会话状态管理

```typescript
// stores/useSessionStore.ts
interface SessionState {
  sessionId: string | null
  role: 'owner' | 'guest'
  controlState: 'owner_hold' | 'guest_hold' | 'none'
  participants: Participant[]
  
  // Actions
  createSession: () => Promise<string>
  joinSession: (sessionId: string) => Promise<void>
  requestControl: () => Promise<void>
  grantControl: (userId: string) => Promise<void>
}
```
