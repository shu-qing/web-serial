## 1. 前端性能优化

### 1.1 虚拟滚动（Virtual Scrolling）

#### 1.1.1 问题背景

当接收数据量达到数千甚至数万行时，DOM 元素过多会导致：
- 页面渲染卡顿
- 内存占用过高
- 滚动不流畅

#### 1.1.2 解决方案

使用虚拟滚动技术，只渲染可见区域的 DOM 元素。

**技术选型**：
- `react-window` 或 `react-virtualized`（推荐 `react-window`，更轻量）

**实现示例**：

```typescript
import { FixedSizeList } from 'react-window'

interface LogEntry {
  id: string
  timestamp: number
  data: string
  direction: 'rx' | 'tx'
}

const VirtualizedLogList: React.FC<{ logs: LogEntry[] }> = ({ logs }) => {
  const Row = ({ index, style }: { index: number; style: React.CSSProperties }) => {
    const log = logs[index]
    return (
      <div style={style} className="log-entry">
        <span className="timestamp">{formatTime(log.timestamp)}</span>
        <span className={`direction ${log.direction}`}>
          {log.direction === 'rx' ? '←' : '→'}
        </span>
        <span className="data">{log.data}</span>
      </div>
    )
  }

  return (
    <FixedSizeList
      height={600}        // 容器高度
      itemCount={logs.length}
      itemSize={30}       // 每项高度
      width="100%"
    >
      {Row}
    </FixedSizeList>
  )
}
```

**性能指标**：
- 支持 100,000+ 行数据流畅渲染
- 60 FPS 滚动性能
- 内存占用减少 90%+

#### 1.1.3 动态高度支持

对于内容高度不固定的场景，使用 `VariableSizeList`：

```typescript
import { VariableSizeList } from 'react-window'

const getItemSize = (index: number) => {
  const log = logs[index]
  // 根据数据内容计算高度
  const lines = log.data.split('\n').length
  return Math.min(lines * 20 + 10, 200) // 最小 20px，最大 200px
}

<VariableSizeList
  height={600}
  itemCount={logs.length}
  itemSize={getItemSize}
  width="100%"
>
  {Row}
</VariableSizeList>
```

### 1.2 背压处理（Backpressure）

#### 1.2.1 问题背景

当串口数据接收速率超过渲染能力时：
- 数据积压
- 内存持续增长
- 最终导致浏览器崩溃

#### 1.2.2 解决方案

实现背压机制，当缓冲区超过阈值时自动清理旧数据。

**缓冲区管理策略**：

```typescript
class DataBuffer {
  private buffer: LogEntry[] = []
  private maxSize = 100000  // 最大行数
  private maxBytes = 10 * 1024 * 1024  // 最大 10 MB

  add(entry: LogEntry): void {
    this.buffer.push(entry)

    // 检测是否超限
    if (this.buffer.length > this.maxSize) {
      // 删除最旧的 10% 数据
      const removeCount = Math.floor(this.maxSize * 0.1)
      this.buffer = this.buffer.slice(removeCount)
      this.notifyUser('缓冲区已满，已清理旧数据')
    }

    // 检测字节数限制
    const totalBytes = this.calculateTotalBytes()
    if (totalBytes > this.maxBytes) {
      // 删除最旧的 20% 数据
      const removeCount = Math.floor(this.buffer.length * 0.2)
      this.buffer = this.buffer.slice(removeCount)
    }
  }

  private calculateTotalBytes(): number {
    return this.buffer.reduce((sum, entry) => {
      return sum + new TextEncoder().encode(entry.data).length
    }, 0)
  }
}
```

**采样显示（高负载模式）**：

```typescript
class HighLoadMode {
  private samplingRate = 10  // 每 10 条显示 1 条

  shouldDisplay(index: number): boolean {
    // 当接收速率 > 200 KB/s 时启用采样
    if (this.receiveRate > 200 * 1024) {
      return index % this.samplingRate === 0
    }
    return true
  }
}
```

### 1.3 数据分块渲染

#### 1.3.1 批量更新策略

避免频繁的 DOM 更新，使用批量更新：

```typescript
class BatchRenderer {
  private pendingUpdates: LogEntry[] = []
  private batchSize = 100
  private renderInterval = 100  // 100ms 渲染一次

  add(entry: LogEntry): void {
    this.pendingUpdates.push(entry)

    if (this.pendingUpdates.length >= this.batchSize) {
      this.flush()
    }
  }

  private flush(): void {
    if (this.pendingUpdates.length === 0) return

    const updates = this.pendingUpdates.splice(0)
    
    // 使用 requestAnimationFrame 批量更新
    requestAnimationFrame(() => {
      this.render(updates)
    })
  }

  start(): void {
    // 定时批量刷新
    setInterval(() => this.flush(), this.renderInterval)
  }
}
```

将数据解析任务移到 Web Worker，避免阻塞主线程：

```typescript
// main.ts
const worker = new Worker(new URL('./data-processor.worker.ts', import.meta.url))

worker.postMessage({ type: 'process', data: rawData })

worker.onmessage = (event) => {
  const { type, result } = event.data
  if (type === 'processed') {
    updateUI(result)
  }
}

// data-processor.worker.ts
self.onmessage = (event) => {
  const { type, data } = event.data
  
  if (type === 'process') {
    // 解析数据
    const parsed = parseData(data)
    
    // 编码转换
    const converted = convertEncoding(parsed)
    
    self.postMessage({
      type: 'processed',
      result: converted
    })
  }
}
```

### 2.2 批量发送

#### 2.2.1 消息合并

将多个小消息合并为单个大消息：

```typescript
class MessageBatcher {
  private messages: any[] = []
  private batchInterval = 100  // 100ms
  private maxBatchSize = 50

  add(message: any): void {
    this.messages.push(message)

    if (this.messages.length >= this.maxBatchSize) {
      this.flush()
    }
  }

  flush(): void {
    if (this.messages.length === 0) return

    const batch = {
      type: 'batch',
      messages: this.messages.splice(0)
    }

    this.send(batch)
  }

  start(): void {
    setInterval(() => this.flush(), this.batchInterval)
  }
}
```

## 3. 缓存优化

### 3.1 浏览器缓存

#### 3.1.1 Service Worker 缓存

使用 Service Worker 缓存静态资源：

```typescript
// service-worker.ts
self.addEventListener('fetch', (event) => {
  event.respondWith(
    caches.match(event.request).then((response) => {
      return response || fetch(event.request)
    })
  )
})
```

#### 3.1.2 内存缓存

对于频繁访问的数据，使用内存缓存：

```typescript
class MemoryCache {
  private cache = new Map<string, { data: any; timestamp: number }>()
  private ttl = 60 * 1000  // 1 分钟

  get(key: string): any | null {
    const entry = this.cache.get(key)
    if (!entry) return null

    if (Date.now() - entry.timestamp > this.ttl) {
      this.cache.delete(key)
      return null
    }

    return entry.data
  }

  set(key: string, data: any): void {
    this.cache.set(key, {
      data,
      timestamp: Date.now()
    })
  }
}
```

## 4. 代码优化

### 4.1 代码分割

#### 4.1.1 路由级代码分割

使用 React.lazy 和 Suspense：

```typescript
import { lazy, Suspense } from 'react'

const HomePage = lazy(() => import('./pages/HomePage'))
const SessionPage = lazy(() => import('./pages/SessionPage'))

function App() {
  return (
    <Suspense fallback={<Loading />}>
      <Routes>
        <Route path="/" element={<HomePage />} />
        <Route path="/session" element={<SessionPage />} />
      </Routes>
    </Suspense>
  )
}
```

#### 4.1.2 组件级代码分割

对于大型组件，按需加载：

```typescript
const HeavyComponent = lazy(() => import('./HeavyComponent'))

function App() {
  const [showHeavy, setShowHeavy] = useState(false)

  return (
    <>
      <button onClick={() => setShowHeavy(true)}>加载组件</button>
      {showHeavy && (
        <Suspense fallback={<Loading />}>
          <HeavyComponent />
        </Suspense>
      )}
    </>
  )
}
```
