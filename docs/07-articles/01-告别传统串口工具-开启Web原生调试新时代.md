## 核心特点

- **智能桥接模式**：自动检测双方设备状态，智能适配 4 种场景
  - 双设备桥接：连接两个物理设备，实现设备间透明通信
  - 单设备远程访问：无设备用户可远程控制设备，完美解决远程技术支持难题
  - 纯软件测试：双方都无设备时，可进行教学演示和产品功能验证
  - 自动 UI 调整：根据设备状态智能启用/禁用发送区，无需手动配置

- **会话共享模式**：通过 6 位邀请码，多人实时协作
  - 自动发送权管理：协作者加入时自动获得发送权，双方可随时抢占控制权
  - 实时数据同步：所有参与者看到相同的数据流，WebRTC P2P 传输，延迟低于 100ms
  - 支持最多 5 人同时参与，适合团队协作和教学演示

- **零安装使用**：基于浏览器 Web Serial API，无需下载安装任何软件

- **跨平台支持**：支持 Windows、macOS、Linux，只要有 Chrome 或 Edge 浏览器即可

- **免费使用**：支持 Google、GitHub、微信等多种登录方式
