## 1. 默认管理员账号

### 1.1 管理员账号信息

**⚠️ 重要：首次部署后请立即修改密码！**

| 项目 | 值 |
|------|-----|
| **邮箱** | `webserialtool@gmail.com` |
| **密码** | `admin@webserial` |
| **角色** | `admin` |
| **状态** | 已验证邮箱，已激活 |

### 1.2 创建/重置管理员账号

#### 方式 1：重置数据库并创建管理员（推荐）

```bash
cd ~/projects/web-serial/backend
npm run reset:db
```

这会：
- 删除所有数据库数据和迁移历史
- 重新创建数据库表结构
- 自动创建管理员账号

#### 方式 2：仅创建管理员账号（数据库已存在）

```bash
cd ~/projects/web-serial/backend
npm run prisma:seed
```

### 1.3 验证管理员账号

```bash
# 进入数据库容器
docker-compose exec postgres psql -U webserial -d web_serial

# 查询管理员账号
SELECT email, username, role, "isEmailVerified" FROM users WHERE email = 'webserialtool@gmail.com';
```

### 1.4 修改管理员密码

登录系统后，在用户设置中修改密码。或通过数据库直接修改：

```bash
# 使用 Prisma Studio（推荐）
docker-compose exec backend npx prisma studio

# 或直接使用 SQL（需要先加密密码）
# 不推荐，建议使用应用界面修改
```
