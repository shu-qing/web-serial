# 部署快速开始

> 文档版本：2.0.0  
> 最后更新：2025-11-11

## 前置条件

- ✅ 域名: `www.webserialtool.com` (已在 NameSilo 注册)
- ✅ 服务器: Ubuntu 24.04 (阿里云)
- 📋 需要准备: 服务器 IP 地址和 SSH 访问权限

## 🚀 一键部署（推荐）

### 1. 上传代码到服务器

在**本地电脑**执行：

```bash
# 方式 A: 使用 rsync (推荐)
rsync -avz --exclude 'node_modules' --exclude '.git' \
  /Users/shuqing/code/web-serial/ \
  root@<服务器IP>:/root/projects/web-serial/

# 方式 B: 使用 scp
cd /Users/shuqing/code/web-serial
tar czf web-serial.tar.gz --exclude 'node_modules' --exclude '.git' .
scp web-serial.tar.gz root@<服务器IP>:/root/

# 然后在服务器上解压
ssh root@<服务器IP>
mkdir -p /root/projects/web-serial
cd /root/projects/web-serial
tar xzf /root/web-serial.tar.gz
```

### 2. 运行一键部署脚本

连接到服务器并执行：

```bash
ssh root@<服务器IP>

# 进入项目目录
cd /root/projects/web-serial

# 运行部署脚本
bash scripts/deploy.sh
```

脚本会自动完成：
- ✅ 检查并安装必要软件（Docker、Node.js、Nginx）
- ✅ 创建环境变量文件
- ✅ 启动数据库和后端服务
- ✅ 构建和部署前端
- ✅ 配置 Nginx 反向代理
- ✅ 配置 SSL 证书（可选）

## 🔧 域名配置

### 在 NameSilo 配置 DNS

1. 登录 [NameSilo](https://www.namesilo.com/)
2. 进入域名管理
3. 选择 `webserialtool.com`
4. 添加以下 DNS 记录：

| 类型 | 主机名 | 值 | TTL |
|------|--------|-----|-----|
| A | @ | `<阿里云服务器IP>` | 3600 |
| A | www | `<阿里云服务器IP>` | 3600 |

5. 等待 DNS 生效（通常 10-30 分钟）

### 验证 DNS

```bash
# 在本地或服务器执行
dig www.webserialtool.com
ping www.webserialtool.com
```

## 🔐 SSL 证书配置

DNS 生效后，在服务器上执行：

```bash
sudo certbot --nginx -d webserialtool.com -d www.webserialtool.com
```

按提示输入邮箱并同意服务条款。Certbot 会自动配置 HTTPS。

## 🛠️ 常用运维命令

### 查看服务状态

```bash
# 监控面板（推荐）
cd /root/projects/web-serial
bash scripts/monitor.sh

# 查看 Docker 容器
cd /root/projects/web-serial/backend
docker-compose ps

# 查看后端日志
docker-compose logs -f backend

# 查看 Nginx 日志
sudo tail -f /var/log/nginx/webserialtool.com.access.log
sudo tail -f /var/log/nginx/webserialtool.com.error.log
```

### 重启服务

```bash
# 重启后端
cd /root/projects/web-serial/backend
docker-compose restart backend

# 重启 Nginx
sudo systemctl restart nginx

# 重启数据库（谨慎操作）
docker-compose restart postgres
```

### 更新代码

```bash
# 使用更新脚本（推荐）
cd /root/projects/web-serial
bash scripts/update-deployment.sh

# 手动更新
cd /root/projects/web-serial
git pull  # 如果使用 Git
cd backend && docker-compose up -d --build backend
cd ../frontend && npm run build && sudo cp -r dist/* /var/www/webserialtool.com/
```

### 数据库备份

```bash
# 手动备份
bash ~/backup-db.sh

# 设置自动备份（每天凌晨 2 点）
crontab -e
# 添加: 0 2 * * * /root/backup-db.sh >> /root/backup.log 2>&1
```

### 恢复数据库

```bash
bash /root/projects/web-serial/scripts/restore-db.sh
```

## 🐛 常见问题排查

### 1. 无法访问网站

```bash
# 检查 DNS
dig www.webserialtool.com

# 检查防火墙
sudo ufw status

# 检查 Nginx
sudo systemctl status nginx
sudo nginx -t

# 查看 Nginx 错误日志
sudo tail -100 /var/log/nginx/error.log
```

### 2. API 请求 404

```bash
# 检查后端服务
cd /root/projects/web-serial/backend
docker-compose ps
docker-compose logs backend

# 测试 API
curl http://localhost:3001/health
```

### 3. 数据库连接失败

```bash
# 检查数据库容器
docker-compose ps postgres
docker-compose logs postgres

# 检查环境变量
cat backend/.env | grep DATABASE_URL
```

### 4. WebSocket 连接失败

```bash
# 检查 Nginx WebSocket 配置
sudo cat /etc/nginx/sites-available/webserialtool.com | grep -A 10 "/ws/"

# 确认有以下配置：
# proxy_set_header Upgrade $http_upgrade;
# proxy_set_header Connection "Upgrade";

# 重启 Nginx
sudo systemctl restart nginx
```

### 5. SSL 证书问题

```bash
# 查看证书状态
sudo certbot certificates

# 手动续期
sudo certbot renew

# 测试自动续期
sudo certbot renew --dry-run
```

## 📊 性能优化

### 启用 Gzip 压缩

```bash
sudo vim /etc/nginx/nginx.conf
```

确认以下配置已启用：

```nginx
gzip on;
gzip_vary on;
gzip_proxied any;
gzip_comp_level 6;
gzip_types text/plain text/css text/xml text/javascript 
           application/json application/javascript application/xml+rss;
```

### 配置缓存

前端静态资源已配置 1 年缓存。如需调整：

```bash
sudo vim /etc/nginx/sites-available/webserialtool.com
```

## 🔒 安全建议

### 1. 更改 SSH 端口

```bash
sudo vim /etc/ssh/sshd_config
# 修改 Port 22 为其他端口，如 2222
sudo systemctl restart sshd

# 更新防火墙规则
sudo ufw allow 2222/tcp
sudo ufw delete allow 22/tcp
```

### 2. 禁用 root 登录

```bash
# 先创建普通用户
sudo adduser deploy
sudo usermod -aG sudo deploy

# 测试普通用户 sudo 权限
su - deploy
sudo ls

# 禁用 root SSH 登录
sudo vim /etc/ssh/sshd_config
# 修改 PermitRootLogin yes 为 no
sudo systemctl restart sshd
```

### 3. 安装 Fail2Ban

```bash
sudo apt install -y fail2ban
sudo systemctl start fail2ban
sudo systemctl enable fail2ban
```

### 4. 定期更新

```bash
# 每周执行
sudo apt update && sudo apt upgrade -y
```
