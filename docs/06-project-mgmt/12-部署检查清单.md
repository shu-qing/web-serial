## 🚀 部署步骤

### 步骤 1: 上传代码 (5分钟)
```bash
# 从本地上传到服务器
cd /Users/shuqing/code/web-serial
rsync -avz --exclude 'node_modules' --exclude '.git' \
  ./ root@<服务器IP>:/root/projects/web-serial/
```
- [ ] 代码上传完成
- [ ] 文件完整性检查

### 步骤 2: 运行部署脚本 (30分钟)
```bash
# SSH 连接服务器
ssh root@<服务器IP>

# 运行一键部署
cd /root/projects/web-serial
bash scripts/deploy.sh
```
- [ ] Docker 安装完成
- [ ] Node.js 安装完成
- [ ] Nginx 安装完成
- [ ] 环境变量已配置
- [ ] 数据库已启动

### 步骤 3: 配置 SSL (10分钟)
```bash
# 等待 DNS 生效后执行
sudo certbot --nginx -d webserialtool.com -d www.webserialtool.com
```
- [ ] DNS 已解析

## 🔧 常用命令速查

### 查看状态
```bash
# 监控面板
bash /root/projects/web-serial/scripts/monitor.sh

# Docker 状态
cd /root/projects/web-serial/backend && docker-compose ps

# 后端日志
docker-compose logs -f backend

# Nginx 日志
sudo tail -f /var/log/nginx/webserialtool.com.access.log
```

### 重启服务
```bash
# 重启后端
cd /root/projects/web-serial/backend
docker-compose restart backend

# 重启 Nginx
sudo systemctl restart nginx

# 重启所有
docker-compose restart && sudo systemctl restart nginx
```

### 更新代码
```bash
cd /root/projects/web-serial
bash scripts/update-deployment.sh
```

### 数据库操作
```bash
# 备份
bash ~/backup-db.sh

# 恢复
bash /root/projects/web-serial/scripts/restore-db.sh
```

## 🐛 故障排查

### 问题：网站无法访问
```bash
1. 检查 DNS: dig www.webserialtool.com
2. 检查防火墙: sudo ufw status
3. 检查 Nginx: sudo systemctl status nginx
4. 查看错误日志: sudo tail -100 /var/log/nginx/error.log
```

### 问题：API 404
```bash
1. 检查后端: docker-compose ps
2. 查看日志: docker-compose logs backend
3. 测试本地: curl http://localhost:3001/health
4. 检查环境变量: cat backend/.env
```

### 问题：数据库连接失败
```bash
1. 检查容器: docker-compose ps postgres
2. 查看日志: docker-compose logs postgres
3. 检查连接: docker exec web-serial-postgres psql -U webserial -d web_serial -c "SELECT 1"
```
