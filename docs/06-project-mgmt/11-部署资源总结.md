## 🎯 部署步骤概览

### 方案一：一键部署（推荐，约 30 分钟）

```bash
# 1. 上传代码到服务器
rsync -avz --exclude 'node_modules' --exclude '.git' \
  /Users/shuqing/code/web-serial/ \
  root@<服务器IP>:/root/projects/web-serial/

# 2. 连接服务器并运行部署脚本
ssh root@<服务器IP>
cd /root/projects/web-serial
bash scripts/deploy.sh
```

## ⚙️ 关键配置说明

### 1. 后端环境变量 (backend/.env)

```env
# 必须配置的项目
NODE_ENV=production
PORT=3001
DATABASE_URL="postgresql://webserial:密码@postgres:5432/web_serial?schema=public"
JWT_SECRET="生成的强随机密钥"  # 使用: openssl rand -base64 48
CORS_ORIGIN="https://www.webserialtool.com"
FRONTEND_URL="https://www.webserialtool.com"

# 可选配置（邮件功能）
EMAIL_HOST="smtp.example.com"
EMAIL_PORT=587
EMAIL_USER="noreply@webserialtool.com"
EMAIL_PASSWORD="邮箱密码或授权码"
EMAIL_FROM="WebSerialTool <noreply@webserialtool.com>"
```

生成 JWT_SECRET：
```bash
openssl rand -base64 48
```

### 2. 前端环境变量 (frontend/.env.production)

```env
VITE_API_URL=https://www.webserialtool.com/api
VITE_WS_URL=wss://www.webserialtool.com/ws
```

### 3. 域名 DNS 配置

在 NameSilo 添加 A 记录：

| 类型 | 主机名 | 值 | TTL |
|------|--------|-----|-----|
| A | @ | `<服务器IP>` | 3600 |
| A | www | `<服务器IP>` | 3600 |

## 🐛 故障排查流程

### 1. 网站无法访问
```bash
# 检查顺序
1. DNS 是否解析: dig www.webserialtool.com
2. 防火墙: sudo ufw status
3. Nginx: sudo systemctl status nginx
4. 后端: docker-compose ps
5. 日志: sudo tail -100 /var/log/nginx/error.log
```

### 2. API 错误
```bash
# 检查顺序
1. 后端状态: docker-compose ps
2. 后端日志: docker-compose logs backend
3. 数据库: docker-compose logs postgres
4. 环境变量: cat backend/.env
5. API 测试: curl http://localhost:3001/health
```

### 3. WebSocket 失败
```bash
# 检查 Nginx WebSocket 配置
sudo cat /etc/nginx/sites-available/webserialtool.com | grep -A 5 "/ws/"

# 必须包含
# proxy_set_header Upgrade $http_upgrade;
# proxy_set_header Connection "Upgrade";
```

```
配置文件:
  - 后端环境变量: /root/projects/web-serial/backend/.env
  - Nginx 配置: /etc/nginx/sites-available/webserialtool.com

  - Nginx 访问: /var/log/nginx/webserialtool.com.access.log
  - Nginx 错误: /var/log/nginx/webserialtool.com.error.log
  - 系统日志: /var/log/syslog

数据目录:
  - 前端文件: /var/www/webserialtool.com/
  - 数据库备份: ~/backups/database/
  - 上传文件: /root/projects/web-serial/backend/uploads/
```

### 紧急命令
```bash
# 查看所有服务状态
docker-compose ps && sudo systemctl status nginx

# 重启所有服务
cd /root/projects/web-serial/backend && \
  docker-compose restart && \
  sudo systemctl restart nginx

# 查看实时日志
docker-compose logs -f backend

# 紧急回滚（前端）
sudo cp -r /var/www/webserialtool.com.backup.* /var/www/webserialtool.com/

# 紧急回滚（后端）
docker-compose down backend
docker-compose up -d backend
```
