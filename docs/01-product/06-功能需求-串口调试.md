# 功能需求：本地串口调试

> 文档版本：1.1.0  
> 最后更新：2025-10-31  
> 负责人：产品经理

---

## 1. 功能概述

本地串口调试是本产品的核心功能，提供完整的串口设备连接、配置、数据收发、日志管理能力。基于浏览器 Web Serial API 实现，无需安装任何插件或驱动程序。

---

## 2. 设备访问与连接

### 2.1 设备列表获取
**功能描述**：列出当前系统可用的串口设备

**详细需求**：
- ✅ 调用 `navigator.serial.getPorts()` 获取已授权设备
- ✅ 点击"选择新设备"触发浏览器串口选择对话框
- ✅ 显示设备信息：端口名、制造商、产品ID、供应商ID（如有）
- ✅ 记住最近使用的 5 个设备，快速选择
- ✅ **支持虚拟串口**：用于产品调试和测试（虚拟串口和真实物理串口）

**交互流程**：
1. 用户点击"连接设备"按钮
2. 如果是首次连接，浏览器弹出设备选择对话框
3. 用户选择设备后，系统申请串口权限
4. 权限授予后，设备加入"最近使用"列表
5. 显示设备信息卡片

**异常处理**：
- 无设备可用：提示"未检测到串口设备，请检查设备连接"
- 权限拒绝：提示"需要串口访问权限"并引导重试
- 端口被占用：显示占用信息，提供重试按钮

**相关技术**：Web Serial API、浏览器权限管理

### 2.2 连接管理

#### 2.2.1 建立连接
**功能描述**：按照配置参数打开串口连接

**详细需求**：
- ✅ 使用当前配置的波特率、数据位等参数调用 `port.open(options)`
- ✅ 连接过程中显示加载状态（进度条或 Spinner）
- ✅ 连接成功后更新界面状态（连接图标、禁用重连按钮）
- ✅ 统计连接建立耗时

**参数支持**：
```javascript
{
  baudRate: 115200,        // 波特率
  dataBits: 8,             // 数据位
  parity: 'none',          // 校验位
  stopBits: 1,             // 停止位
  flowControl: 'none',     // 流控制
  bufferSize: 65536        // 缓冲区大小
}
```

#### 2.2.2 断开连接
**功能描述**：安全关闭串口连接

**详细需求**：
- ✅ 先停止读取流，再关闭连接
- ✅ 提示用户确认（如有未保存数据）
- ✅ 清理接收缓冲区（可选：询问是否保留最后 N 行）
- ✅ 释放设备占用

#### 2.2.3 重连机制
**功能描述**：快速重新连接上次设备

**详细需求**：
- ✅ 一键重连按钮（绿色连接图标）
- ✅ 自动使用上次配置
- ✅ 连接失败自动重试（3 次，间隔 2 秒）

## 3. 串口参数配置

### 3.1 基础参数配置

#### 3.1.1 波特率（Baud Rate）
**功能描述**：设置数据传输速率

**详细需求**：
- ✅ 常用预设：9600, 19200, 38400, 57600, 115200, 230400, 460800, 921600
- ✅ 自定义输入：支持 300 - 4000000 范围
- ✅ 连接时验证波特率有效性
- ✅ 最近使用优先显示（最多 10 个）

#### 3.1.2 数据位（Data Bits）
**功能描述**：每个字符的数据位数

**详细需求**：
- ✅ 可选：5, 6, 7, 8
- ✅ 默认：8

#### 3.1.3 校验位（Parity）
**功能描述**：数据校验方式

**详细需求**：
- ✅ 可选：none, even, odd, mark, space
- ✅ 默认：none
- ✅ 图标提示：✓ none, ✓ even, ✓ odd

#### 3.1.4 停止位（Stop Bits）
**功能描述**：字符结束标志位数

**详细需求**：
- ✅ 可选：1, 1.5, 2
- ✅ 默认：1

#### 3.1.5 流控制（Flow Control）
**功能描述**：数据流控制方式

**详细需求**：
- ✅ 可选：none, hardware, software
- ✅ 默认：none
- ✅ 选择 hardware 时验证设备是否支持 RTS/CTS

**配置文件布局**：
```
┌─────────────────────────────────┐
│ 串口配置                        │
├─────────────────────────────────┤
│ 波特率:  [115200 ▼]            │
│ 数据位:  [8 ▼]                 │
│ 校验位:  [None ▼]              │
│ 停止位:  [1 ▼]                 │
│ 流控制:  [None ▼]              │
└─────────────────────────────────┘
```

---

### 3.2 高级配置

#### 3.2.1 行结束符配置
**功能描述**：设置发送和接收时的行结束符

**详细需求**：
- ✅ 发送端行结束符：None, CR (\r), LF (\n), CRLF (\r\n)
- ✅ 接收端行结束符：None, CR, LF, CRLF, Auto（自动识别）
- ✅ 独立配置发送/接收
- ✅ 发送时自动追加选定的行结束符
- ✅ 接收时根据配置过滤或保留行结束符

#### 3.2.2 字符编码
**功能描述**：数据编码格式

**详细需求**：
- ✅ 可选：UTF-8, ASCII, HEX（十六进制）
- ✅ 支持切换视图而不重连（接收区实时转换）
- ✅ 发送输入框支持 UTF-8 和 HEX 两种输入模式
- ✅ HEX 模式：每字节两位十六进制数，空格分隔

**示例**：
```
文本模式：Hello World
HEX 模式：48 65 6C 6C 6F 20 57 6F 72 6C 64
```

#### 3.2.3 接收缓冲区配置
**功能描述**：控制接收数据的缓冲区大小

**详细需求**：
- ✅ 大小限制：最大 100,000 行或 10 MB
- ✅ 超过限制自动清理最旧数据（循环队列）
- ✅ 可手动清屏（保留最近 100 行）
- ✅ 显示当前缓冲区占用情况

## 4. 数据收发

### 4.1 接收区

#### 4.1.1 数据显示
**功能描述**：实时显示接收到的串口数据

**详细需求**：
- ✅ 虚拟滚动（Virtual Scrolling）支持大流量
- ✅ **自动换行控制**（新增）：用户可选择自动换行或横向滚动
  - 默认：开启自动换行（适合文本日志）
  - HEX模式建议：关闭换行（保持数据包完整性）
  - 快捷键：Ctrl+W 切换
  - 配置云端同步
- ✅ 行号显示（可选开关）
- ✅ 时间戳：显示每条数据的接收时间（可选）
- ✅ 方向标识：接收数据显示绿色箭头 →
- ✅ 自动滚动开关（连接时默认开启）
- ✅ 双击行可复制单行内容

**数据格式**：
```
[14:32:15.123] → Hello World from device
[14:32:15.234] → Device is ready
```

#### 4.1.2 数据高亮
**功能描述**：关键字高亮显示

**详细需求**：
- ✅ 用户可配置关键字列表（最多 20 个）
- ✅ 支持正则表达式
- ✅ 支持多颜色配置
- ✅ 预设常用关键字：
  - ERROR → 红色背景
  - WARN → 黄色背景
  - INFO → 蓝色背景
  - OK/SUCCESS → 绿色背景

**实现**：
```javascript
highlightRules: [
  { pattern: /ERROR/i, color: '#ff4444' },
  { pattern: /WARN/i, color: '#ffaa00' }
]
```

#### 4.1.3 数据过滤
**功能描述**：按条件过滤显示

**详细需求**：
- ✅ 文本搜索过滤（实时高亮匹配）
- ✅ 正则表达式过滤
- ✅ 方向过滤（仅接收/仅发送/全部）
- ✅ 时间范围过滤
- ✅ 显示过滤统计：`显示 1,234 行 / 总计 5,678 行`

---

### 4.2 发送区

#### 4.2.1 输入框
**功能描述**：输入要发送的数据

**详细需求**：
- ✅ 单行模式：回车发送，Shift+Enter 换行
- ✅ 多行模式：Enter 换行，Ctrl+Enter 发送
- ✅ 支持 UTF-8 文本输入
- ✅ 支持 HEX 输入（严格校验格式）
- ✅ 字符计数器（字节数/字符数）
- ✅ 发送按钮快捷键：Ctrl+Enter 或 F5

#### 4.2.2 发送历史
**功能描述**：保存最近发送的内容

**详细需求**：
- ✅ 记录最近 100 条发送内容
- ✅ 下拉列表显示（最多显示 20 项）
- ✅ 支持搜索历史
- ✅ 删除单条历史或清空全部
- ✅ 云同步（登录用户）

#### 4.2.3 发送方式
**功能描述**：多种发送模式

**详细需求**：
- ✅ **立即发送**：点击或按 Enter
- ✅ **重复发送**（新增）：设置重复发送间隔，自动重复发送同一条指令
  - 间隔时间：100ms / 500ms / 1s / 2s / 5s / 自定义
  - 发送次数：无限循环 / 指定次数（如：10次）
  - 停止按钮：随时停止重复发送
  - 发送计数：显示已发送次数（如：`发送中 15/100`）
- ✅ **批量发送**：多指令队列按顺序发送
- ✅ **延时发送**：延迟 N 秒后发送
- ✅ 发送状态显示：`发送中...` 或 进度条

**示例 - 重复发送**：
```
指令: AT+STATUS?
间隔: 1s
次数: 无限循环（或指定次数：100）
[发送] [停止]
状态: 发送中 15 次
```

**示例 - 批量发送**：
```
指令1: AT+CONFIG?     [间隔 1s]
指令2: AT+STATUS      [间隔 1s]
指令3: AT+RESET       [间隔 2s]
总计: 3 条，预计耗时: 4 秒
```

### 5.3 导出功能

#### 5.3.1 导出格式
**功能描述**：将日志导出为文件

**支持格式**：

**1. TXT 格式**（纯文本）
```
[14:32:15.123] → [接收] Hello World
[14:32:15.234] → [发送] AT+STATUS?
[14:32:15.345] ← [接收] OK
```

**2. CSV 格式**
```csv
时间戳,方向,数据
2024-01-15 14:32:15.123,接收,Hello World
2024-01-15 14:32:15.234,发送,AT+STATUS?
```

**3. JSON 格式**
```json
{
  "exportTime": "2024-01-15T14:32:15Z",
  "config": {
    "baudRate": 115200,
    "dataBits": 8,
    "parity": "none"
  },
  "logs": [
    {
      "timestamp": "2024-01-15T14:32:15.123Z",
      "direction": "receive",
      "data": "Hello World",
      "encoding": "UTF-8"
    }
  ]
}
```

#### 5.3.2 导出选项
**功能描述**：自定义导出内容，支持灵活的数据过滤和格式配置

**详细需求**：

**1. 数据方向选择**（核心功能）⭐
- ✅ **全部数据**：包含发送和接收（默认）
  - 适用场景：完整会话归档、重现通信过程
  - CSV列：序号、时间戳、方向、数据、字节数
  
- ✅ **仅接收数据**：只导出设备响应和输出
  - 适用场景：分析设备行为、统计响应类型、查找异常响应
  - CSV列：序号、时间戳、数据、字节数、编码
  - 示例：分析ESP32启动日志、统计Modbus响应错误率
  
- ✅ **仅发送数据**：只导出用户发送的指令
  - 适用场景：保存测试指令序列、导入命令库、分享测试步骤
  - CSV列：序号、时间戳、指令、字节数
  - 示例：导出AT指令测试序列，下次直接使用
  
- ⏳ **配对数据**：发送-接收对（第二阶段，需要配对功能）
  - 适用场景：分析响应延迟、找超时指令、计算成功率
  - CSV列：序号、发送时间、发送数据、接收时间、接收数据、延迟(ms)、状态

**2. 时间范围选择**
- ✅ 全部（默认）
- ✅ 最近 N 分钟（5/10/30/60分钟可选）
- ✅ 自定义时间范围（开始时间 - 结束时间）
- ✅ 当前显示（导出搜索/过滤后的结果）

**3. 格式选项**
- ✅ 包含时间戳开关（默认：开启）
- ✅ 包含方向标识开关（默认：开启，仅"全部数据"时显示）
- ✅ 包含配置信息开关（默认：关闭）
  - 配置信息：波特率、数据位、校验位等
  - 位置：文件头部注释
- ⏳ 包含行号开关（可选）
- ✅ 包含字节数统计（默认：开启）

**4. 编码选择**
- ✅ UTF-8（默认，适合文本）
- ✅ HEX（适合二进制协议）
- ⏳ ASCII（第二阶段）

**5. 文件命名**（自动生成）
- ✅ 格式：`serial-{方向}-{日期}-{时间}.{扩展名}`
- ✅ 示例：`serial-接收数据-2025-11-01-143052.csv`
- ✅ 避免覆盖：时间戳精确到秒
- ✅ 用户可修改文件名

**6. 导出示例**

**示例1：仅接收数据导出（CSV）**
```csv
序号,时间戳,数据,字节数,编码
1,2025-11-01 14:30:00.123,OK,2,UTF-8
2,2025-11-01 14:30:01.234,ready,5,UTF-8
3,2025-11-01 14:30:02.345,AT version:2.1.0.0,20,UTF-8
4,2025-11-01 14:30:02.456,SDK version:3.0.0,18,UTF-8
5,2025-11-01 14:30:02.567,OK,2,UTF-8
```

**示例2：仅发送数据导出（TXT）**
```
AT

AT+GMR
AT+CWMODE=1
AT+CWJAP="MyWiFi","password"
AT+CIPSTART="TCP","192.168.1.100",8080
```

**示例3：全部数据导出（CSV）**
```csv
序号,时间戳,方向,数据,字节数
1,2025-11-01 14:30:00.000,发送,AT,2
2,2025-11-01 14:30:00.050,接收,OK,2
3,2025-11-01 14:30:01.000,发送,AT+RST,7
4,2025-11-01 14:30:01.150,接收,OK,2
5,2025-11-01 14:30:01.350,接收,ready,5
```

#### 5.3.3 快捷导出（新增）
**功能描述**：提供一键导出快捷方式，无需打开对话框

**详细需求**：
- ✅ **快捷导出菜单**：
  - 导出全部 (CSV) - 一键导出所有数据
  - 📥 导出接收数据 (CSV) - 一键导出设备响应
  - 📤 导出发送数据 (TXT) - 一键导出指令序列
  - 🔗 导出配对数据 (CSV) - 一键导出发送-接收对（第二阶段）
  - ⚙️ 自定义导出... - 打开完整导出对话框
  
- ✅ **右键菜单导出**：
  - 在接收区右键 → "导出接收数据"
  - 快速导出，无需额外操作
  
- ✅ **快捷键**：
  - `Ctrl+Shift+E` - 导出全部数据（快捷）
  - `Ctrl+Shift+R` - 导出接收数据（快捷）
  - `Ctrl+Shift+S` - 导出发送数据（快捷）

**使用流程**：
```
方式1（快捷菜单）：
  点击"导出▼" → "导出接收数据" → 完成（2秒）

方式2（快捷键）：
  按 Ctrl+Shift+R → 完成（1秒）

方式3（右键）：
  在接收区右键 → "导出接收数据" → 完成（2秒）

方式4（自定义）：
  点击"自定义导出..." → 打开对话框 → 详细配置 → 导出（10秒）
```

## 6. 数据配对与分析（新增）

### 6.1 发送指令与接收数据自动配对

#### 6.1.1 配对功能
**功能描述**：自动匹配发送指令和对应的接收数据

**详细需求**：
- ✅ **自动配对**：
  - 用户发送指令后，系统自动关联后续接收到的数据
  - 配对时间窗口：默认 3 秒（可配置）
  - 配对标识：在接收区显示配对关系（如：颜色标识、缩进显示）
  
- ✅ **配对规则**：
  - 发送指令后，在时间窗口内接收到的所有数据归为一组
  - 支持多行响应（如：AT指令的多行响应）
  - 支持配对超时检测（超时未收到响应）

- ✅ **配对显示**：
  ```
  [14:32:15] → AT+STATUS?           # 发送指令
  ├─ [14:32:15] ← Device: Ready    # 配对的响应1
  └─ [14:32:16] ← Status: OK       # 配对的响应2
  
  [14:32:20] → AT+CONFIG?          # 发送指令
  └─ [14:32:20] ← ERROR: Unknown   # 配对的响应
  ```

#### 6.1.2 测试结果保存
**功能描述**：用户可选择保存和编辑测试结果

**详细需求**：
- ✅ **保存测试用例**：
  - 选择一组配对的发送-接收数据
  - 右键菜单或点击"保存为测试用例"
  - 输入测试用例名称和描述
  - 保存到测试用例库

- ✅ **测试用例属性**：
  - 用例名称：如"查询状态测试"
  - 发送指令：原始发送指令
  - 预期响应：用户编辑预期的响应内容
  - 实际响应：实际接收到的响应
  - 测试结果：通过/失败
  - 备注：测试说明

- ✅ **编辑测试结果**：
  - 双击测试用例打开编辑对话框
  - 修改预期响应
  - 修改测试结果（通过/失败）
  - 添加备注信息

## 7. 状态与统计

  - 🟡 连接中
  - 🟢 已连接

**详细需求**：

- ✅ 发送字节数：`Tx: 2.3 KB`
- ✅ 接收速率：`Rx: 12.5 KB/s`
- ✅ 总行数：`Lines: 1,234`

**功能描述**：显示性能状态

**详细需求**：
- ✅ 接收延迟：P95 延迟（如有）

- ✅ 内存占用：缓冲区大小
- ✅ 性能警告：帧率低于 30 FPS 时提示

## 8. 错误与异常处理

### 8.1 连接错误
| 错误类型 | 用户提示 | 处理方式 |
|---------|---------|---------|
| 端口被占用 | "串口已被其他程序占用" | 提供重试按钮 |
| 设备拔除 | "设备已断开连接" | 自动检测并提示重连 |
| 权限拒绝 | "需要串口访问权限" | 引导重新授权 |
| 配置错误 | "串口配置无效" | 显示具体错误字段 |

### 8.2 数据错误
| 错误类型 | 用户提示 | 处理方式 |
|---------|---------|---------|
| 编码错误 | "数据编码异常" | 以 HEX 显示 |
| 缓冲区溢出 | "缓冲区已满，已清理旧数据" | 自动清理 |
| 发送失败 | "发送超时，请检查设备连接" | 记录错误日志 |

### 8.3 性能警告
- 高流量警告：接收速率 > 100 KB/s 时提示
- 内存警告：缓冲区占用 > 5 MB 时提示
- 渲染卡顿：帧率 < 30 FPS 时提示
