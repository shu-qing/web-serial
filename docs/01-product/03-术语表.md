## 核心术语定义

### 串口通信相关

**SERIAL PORT（串口）**
- 串行端口（Serial Port）
- 用于串行数据传输的物理接口

**WEB SERIAL API**
- 浏览器串口访问 API
- Chrome/Edge 浏览器原生支持
- 本项目核心依赖

**UART**
- Universal Asynchronous Receiver-Transmitter
- 通用异步收发器
- 硬件串口芯片的标准

**BAUD RATE（波特率）**
- 串口通信的数据传输速率
- 单位：bps（bits per second）
- 常用值：9600, 19200, 115200 等

**DATA BITS（数据位）**
- 每个字符传输的数据位数
- 常见值：5, 6, 7, 8
- 本项目默认 8 位

**PARITY（校验位）**
- 串口通信的奇偶校验
- 用于错误检测
- 类型：none, even, odd, mark, space

**STOP BITS（停止位）**
- 串口通信中字符结束的位数
- 常见值：1, 1.5, 2

**FLOW CONTROL（流控制）**
- 串口流量控制机制
- 防止数据溢出丢失
- 类型：none（无）, hardware（硬件）, software（软件）

---

### 数据编码相关

**ASCII**
- 美国信息交换标准代码（American Standard Code for Information Interchange）
- 7 位字符编码标准，共 128 个字符
- 本项目用于纯文本编码模式

**UTF-8**
- Unicode Transformation Format - 8 bit
- 可变长度字符编码
- 本项目默认编码格式

**HEX**
- 十六进制（Hexadecimal）
- 0-9, A-F 表示数值
- 本项目用于 HEX 编码模式

**ENCODING（编码）**
- 字符编码格式
- 本项目支持：UTF-8, ASCII, HEX

---

### 行结束符

**CR**
- Carriage Return（回车符）
- 字符代码：`\r` (0x0D)
- 串口通信中的行结束符之一

**LF**
- Line Feed（换行符）
- 字符代码：`\n` (0x0A)
- Unix/Linux 系统中常见的行结束符

**CRLF**
- Carriage Return + Line Feed
- 字符代码：`\r\n`
- Windows 系统中常见的行结束符

**LINE ENDING（行结束符）**
- 表示一行结束的字符序列
- 常见：CR, LF, CRLF

---

### 数据缓冲与流控

**BUFFER（缓冲区）**
- 内存中临时存储数据的地方
- 本项目指接收数据的缓冲区，用于存储从串口接收的数据
- 大小限制可配置

**BACKPRESSURE（背压）**
- 当数据生成速度大于消费速度时的流量控制机制
- 本项目用于处理高流量串口数据，防止内存溢出

**FIFO**
- First In First Out（先进先出）
- 队列数据结构
- 本项目用于接收缓冲区溢出时的数据清理策略

---

### 远程协作 - WebRTC

**WEBRTC**
- Web Real-Time Communication
- 浏览器实时通信标准
- 本项目用于远程协作的 P2P 连接

**P2P**
- Peer-to-Peer（点对点）
- 两台设备直接通信，不经过服务器

**DATACHANNEL**
- WebRTC 的数据通道
- 用于浏览器间直接传输数据
- 本项目用于远程协作的实时数据传输

**ICE**
- Interactive Connectivity Establishment
- WebRTC 用于建立 P2P 连接的协议
- 收集 STUN/TURN 候选地址

**SDP**
- Session Description Protocol（会话描述协议）
- WebRTC 用于协商连接参数
- 包含媒体格式、网络地址等

**STUN**
- Session Traversal Utilities for NAT
- WebRTC 用于发现公网 IP 地址的服务器

**TURN**
- Traversal Using Relays around NAT
- WebRTC 用于在 NAT 穿透失败时提供中继服务器

**DTLS**
- Datagram Transport Layer Security
- 用于 UDP 传输的加密协议
- WebRTC 使用 DTLS 加密数据通道

**UDP**
- User Datagram Protocol
- 无连接的数据报协议
- WebRTC 使用 UDP 传输数据

---

### 远程协作 - 信令通信

**WEBSOCKET**
- 全双工通信协议
- 本项目用于 WebRTC 信令和中转传输

**WSS**
- WebSocket Secure
- 使用 TLS 加密的 WebSocket 连接

**SESSION（会话）**
- 远程协作的上下文
- 包括参与者、权限、数据流等

## 项目特定术语

### 串口调试功能

**DEVICE ALIAS（设备别名）**
- 用户为串口设备自定义的名称
- 便于识别和管理多设备

**PORT PROFILE（端口配置）**
- 串口通信的完整参数配置
- 包括波特率、数据位、校验位、停止位、流控等

**RECEIVE AREA（接收区）**
- 显示从串口接收的数据的区域

**SEND AREA（发送区）**
- 输入要发送到串口的数据的区域

---

### 远程协作功能

**CONTROL RIGHT（控制权）**
- 远程会话中发送数据的权限
- 只有持有控制权的用户可以向设备发送指令

**DATA MIRROR（数据镜像）**
- 将本地串口数据流实时复制给远程协作者
- 确保所有参与者看到相同内容

**VIRTUAL ECHO（虚拟回显）**
- 协作者发送内容后的显示回显
- 区别于真实设备返回的数据

**AUDIT LOG（审计日志）**
- 记录会话关键操作的日志
- 用于安全和合规审计
