## 1. 功能概述

用户系统提供账户管理、登录认证、配置云端存储与跨设备同步能力。让用户一次配置，全平台使用，个性化体验永不丢失。

**核心价值**：
- ✅ **项目保存**：用户登录后可保存多个串口调试项目（会话），包括配置和数据
- ✅ **配置同步**：串口配置、命令库、偏好设置等云端同步
- ✅ **跨设备访问**：在任意设备登录后自动同步所有项目和配置
- ✅ **数据持久化**：项目和配置永不丢失，即使更换设备也能快速恢复

## 2. 账户体系

### 2.1 账户注册

#### 2.1.1 邮箱密码注册
**功能描述**：使用邮箱和密码创建账户

**详细需求**：
- ✅ 邮箱格式验证（前端 + 后端双重校验）
- ✅ 密码强度要求：
  - 最少 8 位
  - 包含字母和数字
  - 包含特殊字符（推荐）
- ✅ 密码确认一致性检查
- ✅ 发送验证邮件（邮箱验证）
- ✅ 用户协议与隐私政策确认（必选）

**注册流程**：
1. 用户输入邮箱、密码、确认密码
2. 点击"注册"按钮
3. 前端校验通过后，提交到后端 API
4. 后端创建账户（未激活状态）
5. 发送激活链接到邮箱
6. 用户点击邮件链接激活账户
7. 自动登录并跳转主页

**异常处理**：
- 邮箱已注册：提示"该邮箱已被注册，请登录或使用忘记密码"
- 邮件发送失败：显示重发按钮
- 验证码过期：重新请求激活邮件

---

**注意**：当前版本仅支持邮箱注册/登录，OAuth 第三方登录功能未实现，计划在第二阶段实现。

---

### 2.2 账户登录

#### 2.2.1 邮箱密码登录
**功能描述**：使用邮箱和密码登录

**详细需求**：
- ✅ 记住我选项（本地保存登录态，7 天有效）
- ✅ 自动填充上次登录邮箱
- ✅ 显示/隐藏密码开关
- ✅ 忘记密码链接

**登录流程**：
1. 用户输入邮箱和密码
2. 点击"登录"按钮
3. 前端加密后发送到后端
4. 后端验证并返回 JWT Token
5. 前端保存 Token 到 localStorage
6. 跳转到主页并拉取用户配置

**异常处理**：
- 邮箱或密码错误：提示"邮箱或密码错误，请重试"
- 账户未激活：提示"请先激活账户，检查邮箱验证链接"
- 账户被禁用：提示"账户已被禁用，请联系客服"
- 登录频率限制：提示"登录次数过多，请稍后再试"

#### 2.2.2 第三方登录
**功能描述**：使用 OAuth 快速登录

**详细需求**：
- ✅ 点击第三方图标跳转到授权页面
- ✅ 授权成功后回调并自动登录
- ✅ 首次登录补充用户名和头像（可选）
- ✅ 自动关联已有账户（邮箱匹配）

### 2.3 账户安全

#### 2.3.1 密码管理
**功能描述**：密码相关安全操作

**详细需求**：
- ✅ **修改密码**：验证旧密码 → 设置新密码
- ✅ **忘记密码**：邮箱重置链接 → 设置新密码
- ✅ 密码重置链接 1 小时有效
- ✅ 限制重置频率：1 小时内最多 3 次

#### 2.3.2 设备管理
**功能描述**：管理已登录的设备会话

**详细需求**：
- ✅ 显示当前登录设备列表：
  - 设备名称（浏览器 + 操作系统）
  - IP 地址（脱敏显示）
  - 最后活跃时间
  - 当前设备标识
- ✅ 退出指定设备
- ✅ 一键退出所有设备
- ✅ 异常登录提醒（新设备、异地登录）

#### 2.3.3 会话管理
**功能描述**：Token 刷新与过期处理

**详细需求**：
- ✅ JWT Token 7 天有效期
- ✅ Refresh Token 30 天有效期
- ✅ 自动刷新机制（距离过期 1 小时自动刷新）
- ✅ Token 过期提示并引导重新登录

## 3. 配置管理

### 3.1 串口配置（Serial Profile）

#### 3.1.1 默认配置
**功能描述**：用户默认的串口参数配置

**详细需求**：
- ✅ 每个用户仅一份默认配置
- ✅ 覆盖所有基础参数：
  - 波特率、数据位、校验位、停止位、流控制
  - 行结束符（发送/接收）
  - 编码格式
  - 接收缓冲区大小
- ✅ 首次使用自动保存
- ✅ 手动"保存为默认"按钮

**配置同步逻辑**：
```
登录 → 拉取云端默认配置 → 合并本地配置 → 应用到当前会话
修改配置 → 自动保存云端 → 延迟 2 秒（防频繁请求）
```

#### 3.1.2 设备别名配置
**功能描述**：为特定设备保存专有配置

**详细需求**：
- ✅ 根据 USB Vendor ID + Product ID 识别设备
- ✅ 为设备命名别名（如"Arduino Uno"、"ESP32 开发板"）
- ✅ 为每个设备保存独立配置
- ✅ 连接时自动匹配并应用设备配置
- ✅ 手动选择使用设备配置或默认配置

**数据结构**：
```json
{
  "deviceId": "1A86:7523",
  "alias": "CH340 串口模块",
  "config": {
    "baudRate": 9600,
    "dataBits": 8,
    "parity": "none"
  }
}
```

### 3.4 项目保存（新增）

#### 3.4.1 项目保存
**功能描述**：用户登录后可保存多个串口调试项目（会话），包括配置和数据

**详细需求**：
- ✅ **自动保存**：用户创建的会话自动保存为项目
- ✅ **项目属性**：
  - 项目名称（会话名称）
  - 项目描述（可选）
  - 创建时间
  - 最后使用时间
  - 关联设备信息
  - 串口配置参数
  - 接收数据（最近N条，可选）
  - 发送历史
  - 命令库（如果项目有独立的命令库）

- ✅ **手动保存**：
  - 用户可以手动保存当前会话为项目
  - 选择保存内容（配置/数据/历史等）
  - 设置项目名称和描述

#### 3.4.2 项目列表管理
**功能描述**：管理保存的项目列表

**详细需求**：
- ✅ **项目列表**：
  - 显示所有保存的项目
  - 显示项目名称、创建时间、最后使用时间
  - 显示项目状态（已连接/未连接）
  - 支持按名称、时间、状态排序

- ✅ **项目操作**：
  - **打开项目**：恢复项目配置和数据
  - **重命名项目**：修改项目名称和描述
  - **复制项目**：复制项目配置，创建新项目
  - **删除项目**：删除项目及其所有数据（需确认）
  - **导出项目**：导出项目配置和数据
  - **导入项目**：导入项目文件

#### 3.4.3 项目恢复
**功能描述**：从保存的项目恢复会话

**详细需求**：
- ✅ **快速恢复**：
  - 点击项目列表中的项目
  - 自动恢复项目配置
  - 可选恢复接收数据（最近N条）
  - 可选自动连接设备（如果设备可用）

- ✅ **配置恢复**：
  - 恢复串口配置参数
  - 恢复命令库
  - 恢复偏好设置（如果项目有独立的偏好设置）

#### 3.4.4 项目云端同步
**功能描述**：登录用户的项目数据云端同步

**同步内容**：
- ✅ 项目列表和属性
- ✅ 项目配置参数
- ✅ 接收数据（最近N条）
- ✅ 发送历史
- ✅ 命令库（如果项目有独立的命令库）

**同步规则**：
- ✅ 自动同步：项目创建/修改时自动同步
- ✅ 手动同步：用户可手动触发同步
- ✅ 冲突解决：最后修改时间优先

**跨设备使用**：
- ✅ 用户在设备A创建项目，在设备B自动看到
- ✅ 跨设备打开项目时恢复配置和数据
- ✅ 支持离线使用，上线后自动同步

## 4. 同步策略

### 4.1 同步时机

#### 4.1.1 登录同步
**功能描述**：用户登录时拉取云端数据

**详细需求**：
- ✅ 拉取顺序：配置 → 宏 → 历史 → 偏好
- ✅ 显示加载进度（5% / 25% / 75% / 100%）
- ✅ 自动合并冲突（见下文）

#### 4.1.2 实时同步
**功能描述**：修改配置时立即同步

**详细需求**：
- ✅ 延迟同步：2 秒内的多次修改合并为一次请求
- ✅ 批处理策略：最多累积 5 个修改项
- ✅ 离线检测：网络断开时本地缓存，上线后补同步

#### 4.1.3 定时同步
**功能描述**：定期检查云端更新

**详细需求**：
- ✅ 每 5 分钟检测一次版本号
- ✅ 检测到更新后提示用户刷新
- ✅ 可选自动应用更新

---

### 4.2 冲突解决

#### 4.2.1 冲突检测
**功能描述**：识别本地和云端配置冲突

**详细需求**：
- ✅ 使用版本号（lastModifiedAt）比较
- ✅ 检测冲突场景：
  - 不同设备同时修改
  - 离线期间本地修改

#### 4.2.2 冲突解决策略
**功能描述**：自动或手动解决冲突

**详细需求**：
- ✅ **自动合并**（默认）：
  - 简单字段：以最新更新为准
  - 复杂结构（宏列表）：合并去重
- ✅ **手动选择**（可选）：
  - 显示冲突对比对话框
  - 用户选择"使用云端"或"保留本地"
  - 选择后同步生效

**冲突提示示例**：
```
⚠️ 配置冲突检测到
您的配置在两个设备上都有更新
推荐：以最新修改为准（云端）
选项：[使用云端] [保留本地] [对比差异]
```

---

### 4.3 离线支持

#### 4.3.1 本地缓存
**功能描述**：离线状态下使用本地数据

**详细需求**：
- ✅ 使用 IndexedDB 存储本地配置

- ✅ 离线模式下正常使用串口功能
- ✅ 上线后自动同步

#### 4.3.2 冲突队列
**功能描述**：离线期间的修改排队等待同步

**详细需求**：
- ✅ 记录修改时间戳和内容
- ✅ 上线后按时间顺序逐一同步
- ✅ 显示待同步队列数量

## 6. 数据模型

### 6.1 用户模型（User）
```typescript
{
  id: string,                    // UUID
  email: string,                 // 邮箱
  nickname?: string,             // 昵称
  avatar?: string,               // 头像 URL
  authProvider: 'email' | 'google' | 'github',
  passwordHash?: string,         // 密码哈希（邮箱登录）
  isEmailVerified: boolean,      // 邮箱验证状态
  lastLoginAt?: Date,           // 最后登录时间
  createdAt: Date,              // 账户创建时间
  updatedAt: Date               // 更新时间
}
```

### 6.2 串口配置模型（SerialProfile）
```typescript
{
  id: string,
  userId: string,
  name: 'default' | string,      // 'default' 或设备别名
  deviceId?: string,             // USB Vendor:Product ID
  baudRate: number,
  dataBits: 5 | 6 | 7 | 8,
  parity: 'none' | 'even' | 'odd' | 'mark' | 'space',
  stopBits: 1 | 1.5 | 2,
  flowControl: 'none' | 'hardware' | 'software',
  lineEndingSend: 'none' | 'cr' | 'lf' | 'crlf',
  lineEndingParse: 'none' | 'cr' | 'lf' | 'crlf' | 'auto',
  encoding: 'utf-8' | 'ascii' | 'hex',
  bufferSize: number,            // 缓冲区大小（字节）
  isDefault: boolean,
  lastModifiedAt: Date          // 用于冲突检测
}
```

### 6.3 宏命令模型（Macro）
```typescript
{
  id: string,
  userId: string,
  name: string,
  category: string,
  contentTemplate: string,       // 支持 {variable} 插值
  variablesSchema: [             // 变量定义
    {
      name: string,
      type: 'string' | 'number' | 'boolean',
      default: any,
      description?: string
    }
  ],
  createdAt: Date,
  updatedAt: Date
}
```

### 6.4 发送历史模型（SendHistory）
```typescript
{
  id: string,
  userId: string,
  content: string,
  encoding: string,
  createdAt: Date
}
```

### 6.5 用户偏好模型（UserPreference）
```typescript
{
  userId: string,
  theme: 'light' | 'dark' | 'auto',
  fontSize: number,
  fontFamily: string,
  lineHeight: 'compact' | 'normal' | 'comfort',
  autoScroll: boolean,
  showLineNumber: boolean,
  timestampFormat: string,
  highlightRules: [
    { pattern: string, color: string }
  ],
  updatedAt: Date
}
```

## 7. 安全考量

### 7.1 数据加密
- ✅ 密码使用 bcrypt 哈希（10 rounds）
- ✅ 敏感配置字段加密存储（AES-256）
- ✅ HTTPS 传输（TLS 1.3）

### 7.2 权限控制
- ✅ 用户只能访问自己的配置
- ✅ API 请求验证 JWT Token
- ✅ 设备管理需要用户授权

### 7.3 审计日志
- ✅ 记录账户创建、登录、退出
- ✅ 记录敏感配置修改
- ✅ 日志保留 90 天
