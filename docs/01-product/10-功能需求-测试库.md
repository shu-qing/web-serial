## 1. 功能概述

测试库功能提供完整的串口测试管理能力，通过三层结构（测试库 -> 测试单 -> 单元测试）组织和管理测试用例，支持测试执行、结果验证和报告生成。

**架构说明**：
```
测试库（Test Library）
  └─ 测试单（Test Suite）
       └─ 单元测试（Test Case）
```

- **测试库**：按设备或协议组织的测试集合（如"ESP32测试库"、"Modbus设备库"）
- **测试单**：用户自定义的测试分组（如"WiFi连接测试"、"完整初始化流程"）
- **单元测试**：最小的测试单元，包含发送命令、期望响应、断言验证等完整测试要素

**核心价值**：
- ✅ 结构化测试管理，支持复杂测试场景
- ✅ 完整的测试用例定义（命令、期望响应、断言、前置条件）
- ✅ 灵活的执行策略（单个执行、批量执行、选择性执行）
- ✅ 详细的测试结果记录和报告生成
- ✅ AI智能导入，从设备文档自动生成测试用例
- ✅ 智能校验码计算和识别
- ✅ 支持变量和参数化测试

## 2. 命令管理

### 2.1 创建命令

#### 2.1.1 添加命令
**功能描述**：用户可以添加新的发送命令

**详细需求**：
- ✅ 点击"添加命令"按钮
- ✅ 输入命令名称（如"查询状态"、"重启设备"等）
- ✅ 输入命令内容（实际发送的数据）
- ✅ 选择命令分类（可选，便于管理）
- ✅ 设置命令描述（可选，说明命令用途）
- ✅ 设置命令标签（可选，用于搜索）

**命令属性**：
- **命令ID**：自动生成唯一ID
- **命令名称**：用户自定义名称
- **命令内容**：实际发送的数据（支持多行）
- **编码格式**：文本/HEX（继承会话设置或独立设置）
- **行结束符**：无/CR/LF/CRLF（继承会话设置或独立设置）
- **分类**：用户自定义分类
- **标签**：多个标签（用逗号分隔）
- **创建时间**：自动记录
- **使用次数**：自动统计

### 2.2 命令编辑

#### 2.2.1 编辑命令
**功能描述**：修改已保存的命令

**详细需求**：
- ✅ 双击命令项或右键菜单"编辑"
- ✅ 修改命令属性（名称、内容、分类等）
- ✅ 保存修改
- ✅ 取消编辑（不保存）

#### 2.2.2 删除命令
**功能描述**：删除不需要的命令

**详细需求**：
- ✅ 右键菜单"删除"或点击删除按钮
- ✅ 确认对话框（防止误删）
- ✅ 删除后从列表中移除

### 2.3 命令分类

#### 2.3.1 分类管理
**功能描述**：对命令进行分类管理

**详细需求**：
- ✅ 创建分类（如"设备控制"、"数据查询"、"配置命令"等）
- ✅ 命令分配到分类
- ✅ 分类列表显示（树形结构或平铺）
- ✅ 按分类过滤命令

**默认分类**：
- **常用命令**：用户标记为常用的命令

### 3.2 命令发送

#### 3.2.1 快速发送
**功能描述**：从命令库快速发送命令

**发送方式**：
1. **一键发送**：点击命令项旁边的"发送"按钮，直接发送到串口
2. **一键复制到发送窗口**（新增）：点击命令项旁边的"复制"按钮，将命令内容复制到发送区，用户可编辑后再发送
3. **双击发送**：双击命令项直接发送（可配置）
4. **快捷键发送**：为命令设置快捷键（可选，如：F1-F12）

**详细需求**：
- ✅ **一键发送**：
  - 点击"发送"按钮后立即发送到当前会话
  - 无需确认，直接执行
  - 发送后记录使用次数和最后使用时间
  
- ✅ **一键复制到发送窗口**：
  - 点击"复制"按钮后，命令内容填充到发送区
  - 用户可以编辑命令内容
  - 手动点击发送按钮发送
  - 适用于需要微调命令的场景

- ✅ 发送成功后显示提示（可选）
- ✅ 支持发送带变量的命令（提示输入变量值）

#### 3.2.2 命令预览
**功能描述**：发送前预览命令内容

**详细需求**：
- ✅ 鼠标悬停显示完整命令内容
- ✅ 点击命令显示命令详情（对话框）
- ✅ 在详情中可以直接发送或编辑

#### 3.2.3 批量发送（新增）⭐
**功能描述**：支持多条命令序列的自动发送，替代复杂的宏系统

**详细需求**：
- ✅ **多行命令支持**：
  - 在命令内容中输入多行（每行一条指令）
  - 标识：命令内容包含换行符
  - 显示：在命令列表中显示"多行"标识
  
- ✅ **逐行发送模式**：
  - 发送时自动按行拆分
  - 每行作为独立指令发送
  - 行间延迟：可配置（默认1秒）
  - 发送进度：显示"发送中 3/10"
  
- ✅ **批量发送配置**：
  - 行间隔时间：100ms/500ms/1s/2s/5s/自定义
  - 失败处理：继续发送 / 停止发送
  - 发送预览：发送前预览所有指令
  - 随时停止：批量发送过程中可中止

**示例 - 设备初始化序列**：
```
命令名称：ESP32完整初始化
命令内容（多行）：
  AT+RST
  AT+CWMODE=1
  AT+CWJAP="${SSID}","${PASSWORD}"
  AT+CIPSTART="TCP","${SERVER}",${PORT}
  
批量发送配置：
  - 行间隔：2秒
  - 失败处理：停止发送
  - 变量：SSID, PASSWORD, SERVER, PORT

执行流程：
  1. 点击"发送"按钮
  2. 弹出变量输入框
  3. 输入所有变量值
  4. 开始批量发送：
     → AT+RST（等待2秒）
     → AT+CWMODE=1（等待2秒）
     → AT+CWJAP="MyWiFi","12345678"（等待2秒）
     → AT+CIPSTART="TCP","192.168.1.100",8080
  5. 完成，显示"批量发送完成 4/4"
```

**使用场景**：
- 设备初始化流程
- 标准测试序列
- 配置下发流程
- 批量参数设置

**vs 宏命令系统的优势**：
- ✅ 更简单：不需要"宏调用宏"
- ✅ 更直观：看到的就是发送的
- ✅ 更灵活：每行可以是任何指令
- ✅ 覆盖95%场景，但开发成本低

## 4. 命令变量

### 4.1 变量支持
**功能描述**：支持命令中的变量和参数化

**变量类型**：
- ✅ **固定变量**：如时间戳、日期等系统变量
- ✅ **用户变量**：用户自定义变量，发送时输入值
- ✅ **会话变量**：从当前会话获取的值（如设备ID等）

**变量格式**：
```
${variable_name}  # 用户变量
${TIME}          # 系统变量（当前时间）
${DATE}          # 系统变量（当前日期）
${SESSION_ID}    # 会话变量
```

### 4.2 变量输入
**功能描述**：发送带变量的命令时，提示用户输入变量值

**详细需求**：
- ✅ 检测命令中的变量
- ✅ 弹出对话框输入变量值
- ✅ 变量验证（类型、格式、范围等）
- ✅ 替换变量后发送

**示例**：
```
命令内容：AT+CONFIG=${PORT},${BAUD}
用户输入：
  PORT = 8080
  BAUD = 115200
实际发送：AT+CONFIG=8080,115200
```

#### 8.4.2 Modbus协议提取

**原始文档（PDF）**：
```
功能码 0x03 - 读保持寄存器
```

### 10.5 技术实现

#### 10.5.1 校验算法库

**CRC16-Modbus实现**：
```javascript
function calculateCRC16Modbus(data) {
  let crc = 0xFFFF;
  
  for (let byte of data) {
    crc ^= byte;
    
    for (let i = 0; i < 8; i++) {
      if (crc & 0x0001) {
        crc = (crc >> 1) ^ 0xA001;
      } else {
        crc = crc >> 1;
      }
    }
  }
  
  // 低字节在前
  return [(crc & 0xFF), (crc >> 8)];
}

// 使用示例
const data = [0x01, 0x03, 0x00, 0x00, 0x00, 0x0A];
const crc = calculateCRC16Modbus(data);
// 结果：[0xC5, 0xCD]
// 完整命令：01 03 00 00 00 0A C5 CD
```

**累加和实现**：
```javascript
function calculateChecksum(data) {
  let sum = 0;
  for (let byte of data) {
    sum = (sum + byte) & 0xFF;
  }
  return [sum];
}
```

**XOR校验实现**：
```javascript
function calculateXOR(data) {
  let xor = 0;
  for (let byte of data) {
    xor ^= byte;
  }
  return [xor];
}
```

```javascript
async function identifyChecksumAlgorithm(examples) {
  // 1. 准备算法列表
  const algorithms = [
    { name: 'CRC16-Modbus', func: calculateCRC16Modbus, bytes: 2 },
    { name: 'CRC16-CCITT', func: calculateCRC16CCITT, bytes: 2 },
    { name: 'CRC8', func: calculateCRC8, bytes: 1 },
    { name: 'Checksum', func: calculateChecksum, bytes: 1 },
    { name: 'XOR', func: calculateXOR, bytes: 1 }
  ];
  
  // 2. 遍历算法
  for (let algo of algorithms) {
    let matchCount = 0;
    
    for (let example of examples) {
      const data = example.slice(0, -algo.bytes);
      const checksum = example.slice(-algo.bytes);
      const calculated = algo.func(data);
      
      if (arraysEqual(calculated, checksum)) {
        matchCount++;
      }
    }
    
    // 3. 检查是否全部匹配
    if (matchCount === examples.length) {
      return {
        algorithm: algo.name,
        confidence: 1.0,
        matchRate: `${matchCount}/${examples.length}`
      };
    }
  }
  
  return { algorithm: null, confidence: 0 };
}
```
