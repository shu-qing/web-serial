# 核心功能一览

> WebSerialTool 的主要功能特性介绍

---

## 串口调试功能

### 设备连接
- 支持通过 Web Serial API 连接串口设备
- 自动识别已授权设备，快速重连
- 支持虚拟串口，方便测试和演示

### 参数配置
- 完整的串口参数设置：波特率、数据位、校验位、停止位、流控制
- 支持多种编码格式：UTF-8、HEX
- 配置云端保存，跨设备同步

### 数据收发
- 实时数据接收和显示
- 支持文本和十六进制两种显示模式
- 关键字高亮和搜索过滤，快速定位关键数据
- 自动换行控制，适应不同数据类型

### 高级功能
- **循环发送** - 自动重复发送，支持间隔和次数配置
- **DTR/RTS 信号控制** - 支持 Arduino 等设备复位
- **清屏功能** - 一键清理显示区
- **日志导出** - 支持 TXT/CSV 格式导出

---

## 项目管理

- **多项目支持** - 创建和管理多个项目
- **项目切换** - 快速切换不同项目配置
- **云端同步** - 项目配置自动同步到云端
- **跨设备访问** - 登录后可在任何设备访问项目

## 测试库

- **测试库管理** - 创建和管理测试库
- **测试单管理** - 组织测试用例到测试单
- **测试用例** - 创建测试用例，支持变量和校验码
- **测试执行** - 执行测试用例并记录结果
- **结果查看** - 查看历史测试结果

## 远程协作

### 会话共享（邀请码模式）
- 发起者创建会话，生成 6 位邀请码
- 协作者通过邀请码加入会话
- 实时共享串口数据流
- 支持发送权控制，轮流操作

### 智能桥接（连接码模式）
- 自动检测设备连接状态
- 智能调整交互模式：
  - 双方都有设备：设备间透明通信
  - 一方有设备：远程访问控制
  - 双方无设备：纯软件测试
- 完美解决无硬件测试问题
