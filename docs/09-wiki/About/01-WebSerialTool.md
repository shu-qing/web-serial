# 什么是 WebSerialTool

> 了解 WebSerialTool 的核心定位和价值

---

## 产品定位

**WebSerialTool**（网页串口调试工具）是一个基于 Web Serial API 的浏览器原生串口调试工具，让硬件开发者摆脱传统桌面应用的束缚，享受云端化协作的便利。

### 核心价值主张

1. **零安装，即开即用** - 现代浏览器原生支持，无需下载安装桌面应用
2. **云端配置，跨设备同步** - 一次配置，全平台使用，个性化设置永不丢失
3. **实时远程协作** - 支持多人同时调试，零距离远程技术支持
4. **智能化体验** - 配置记忆、指令历史、测试库、自动解析

---

## 与传统工具对比

| 特性 | WebSerialTool | 传统桌面工具（PuTTY、串口助手等） |
|------|--------------|--------------------------------|
| **安装方式** | Web端：零安装，浏览器打开即用 | 需下载安装，占用系统资源 |
| **配置管理** | 云端同步，跨设备访问 | 本地存储，换设备需重新配置 |
| **远程协作** | 原生支持多人协作，实时共享 | 需配合远程桌面，体验差 |
| **更新维护** | Web端：实时更新，无需手动升级 | 需手动下载更新版本 |
| **浏览器支持** | Chrome 89+ / Edge 89+ | N/A |
| **移动端访问** | 支持远程查看（未来） | 不支持 |

## 适用人群

### 主要用户

- **硬件/嵌入式工程师** - 实验室开发、现场调试、日志分析
- **技术支持工程师** - 远程协助客户、故障复现、日志收集
- **培训机构/讲师** - 课堂教学演示、学员实操指导

### 次要用户

- **测试工程师** - 自动化测试集成、批量设备调试
- **学生/学习者** - 学习和实验串口通信
- **工业维护人员** - 现场设备监控和维护

---

## 浏览器兼容性

### 支持的浏览器

- ✅ **Chrome 89+** - 完整支持所有功能
- ✅ **Edge 89+** - 完整支持所有功能
- ❌ **Firefox** - 不支持 Web Serial API
- ❌ **Safari** - 不支持 Web Serial API

### 使用要求

- 必须在 **HTTPS** 或 **localhost** 环境下使用
- 需要用户授权串口设备访问权限
- 部分操作系统可能需要额外的系统权限配置
