# 快速开始指南

> 5 分钟快速上手 WebSerialTool

---

## 环境要求

### 浏览器要求
- **Chrome 89+** 或 **Edge 89+**（必须支持 Web Serial API）
- 必须在 **HTTPS** 或 **localhost** 环境下使用

### 系统要求
- Windows 10+ / macOS 11+ / Linux
- 串口设备已正确连接并安装驱动

---

## 访问方式

1. 打开浏览器（Chrome 或 Edge）
2. 访问 WebSerialTool 网站
3. 无需下载安装，直接使用

---

## 首次使用步骤

### 步骤 1：注册账户（可选）

- 点击右上角"登录"按钮
- 选择"注册"，输入邮箱和密码
- 完成邮箱验证（可选，但推荐）

**提示**：注册账户后可以享受配置云端同步、项目管理等功能。

### 步骤 2：连接设备

1. 点击左侧边栏的"串口连接"按钮
2. 点击"选择设备"按钮
3. 在浏览器弹出的设备列表中选择你的串口设备
4. 点击"连接"按钮

**注意**：首次连接需要授权浏览器访问串口设备。

### 步骤 3：配置串口参数

- **波特率**：根据设备要求设置（常见：9600、115200）
- **数据位**：通常为 8
- **校验位**：通常为 none
- **停止位**：通常为 1
- **流控制**：通常为 none

**提示**：配置会自动保存，下次连接相同设备时会自动应用。

### 步骤 4：开始调试

- **接收数据**：设备发送的数据会自动显示在接收区
- **发送数据**：在发送区输入数据，点击"发送"按钮
- **查看统计**：底部状态栏显示接收/发送字节数

---

## 基本操作演示

### 发送文本数据

1. 在发送区输入文本（如：`AT\r\n`）
2. 选择编码格式（文本或十六进制）
3. 点击"发送"按钮或按 `Ctrl+Enter`

### 查看接收数据

- 接收区实时显示设备返回的数据
- 支持关键字高亮，快速定位关键信息
- 支持搜索过滤，查找特定内容

### 导出日志

1. 点击工具栏的"导出"按钮
2. 选择导出格式（TXT 或 CSV）
3. 下载日志文件
