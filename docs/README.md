## 🚀 生产环境部署

### 快速部署（推荐）

本项目提供完整的自动化部署方案，支持一键部署到生产环境。

#### 📚 部署文档

所有部署文档已归档到 `06-project-mgmt/` 目录：

1. **[部署快速开始](./06-project-mgmt/10-部署快速开始.md)** ⭐ - 5分钟了解部署流程
2. **[生产环境部署指南](./06-project-mgmt/09-生产环境部署指南.md)** - 完整的10步部署说明
3. **[部署资源总结](./06-project-mgmt/11-部署资源总结.md)** - 配置清单、常用命令
4. **[部署检查清单](./06-project-mgmt/12-部署检查清单.md)** - 完整验证清单

#### 🎯 一键部署流程

```bash
# 1. 上传代码到服务器
rsync -avz --exclude 'node_modules' --exclude '.git' \
  ./ user@<server-ip>:/path/to/web-serial/

# 2. SSH 连接并运行部署脚本
ssh user@<server-ip>
cd /path/to/web-serial
bash scripts/deploy.sh

# 3. 按提示完成 DNS、SSL 配置
```

#### 📋 部署要求

- **服务器**: Ubuntu 20.04+ / CentOS 7+
- **域名**: 已注册的域名（推荐）
- **配置**: 2核4G内存起（推荐4核8G）
- **软件**: Docker + Nginx（脚本自动安装）

#### 🛠️ 自动化工具

项目根目录提供了完整的运维脚本：
- `scripts/deploy.sh` - 一键自动部署（安装依赖、配置环境、启动服务）
- `scripts/backup-db.sh` - 数据库自动备份（支持定时任务）
- `scripts/restore-db.sh` - 数据库恢复
- `scripts/update-deployment.sh` - 快速更新部署
- `scripts/monitor.sh` - 服务监控面板
