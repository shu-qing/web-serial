快速开始

📅 最后更新：2025-11-02 🏷️ 标签：入门、教程、基础 👁️ 阅读时间：约 5 分钟

本教程将帮助您快速上手 Web Serial Debugger，完成第一次串口调试任务。整个过程只需 5 分钟！

1. 安装与运行

Web Serial Debugger 提供多种使用方式：

方式一：在线使用（推荐新手）

  • 直接访问 在线版本
  • 无需安装，打开浏览器即可使用
  • 需要使用 Chrome/Edge 89+ 或其他支持 Web Serial API 的浏览器

方式二：桌面应用（推荐专业用户）

  • 前往 下载页面 下载对应平台的安装包
  • 支持 Windows、macOS、Linux
  • 提供更完整的串口支持和离线使用能力

2. 连接设备

连接串口设备是调试的第一步：

  1. 连接硬件：将串口设备通过 USB 数据线连接到电脑
  2. 点击连接按钮：在界面顶部找到蓝色的"连接"按钮并点击
  3. 选择设备：在弹出的设备列表中选择您的串口设备（通常显示为 COM 端口或设备名称）
  4. 确认连接：点击"连接"后，状态指示灯将变为绿色 🟢
💡 提示：如果看不到您的设备，请检查：
- 设备是否正确连接到电脑
- 是否安装了必要的驱动程序
- 是否有其他程序占用了串口

3. 配置串口参数

在连接设备之前，您可能需要配置串口参数以匹配设备要求：

常用参数说明

  • 波特率（Baud Rate）：数据传输速度，常用值有 9600、115200 等
  • 数据位（Data Bits）：每个字符的位数，通常为 8 位
  • 校验位（Parity）：错误检测方式，通常选择 None（无校验）
  • 停止位（Stop Bits）：帧结束标志，通常为 1 位

示例配置

大多数设备使用以下标准配置：

波特率：115200
数据位：8
校验位：None
停止位：1

4. 发送和接收数据

接收数据

连接成功后，设备发送的数据将自动显示在接收区：

  • 每条数据显示时间戳和方向标识（← 表示接收）
  • 可以使用搜索功能快速定位关键数据
  • 勾选"自动滚动"可自动跳转到最新数据
  • 勾选"自动换行"可完整显示长文本

发送数据

向设备发送指令非常简单：

  1. 在发送区输入框中输入要发送的数据（如 AT）
  2. 选择编码格式（ASCII 或 HEX）
  3. 选择行结束符（通常为 \r\n）
  4. 点击"发送"按钮

使用命令库

右侧的命令库可以快速发送常用指令：

  • 点击命令项右侧的 ▶️ 按钮直接发送
  • 点击 📋 按钮复制命令到剪贴板
  • 点击 ✏️ 按钮编辑命令
  • 使用"AI 导入"功能快速导入设备手册中的命令
