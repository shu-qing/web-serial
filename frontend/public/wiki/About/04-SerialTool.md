# 串口调试工具

> WebSerialTool 核心功能：本地串口调试完整指南

---

## 功能概述

串口调试工具是 WebSerialTool 的核心功能，提供完整的串口设备连接、配置、数据收发、日志管理能力。基于浏览器 Web Serial API 实现，无需安装任何插件或驱动程序。

**核心特性**：
- ✅ 零安装，浏览器打开即用
- ✅ 完整的串口参数配置（波特率、数据位、校验位、流控制）
- ✅ 实时数据收发与显示（文本/十六进制）
- ✅ 关键字高亮与搜索过滤
- ✅ 循环发送、DTR/RTS 信号控制
- ✅ 日志导出（TXT/CSV/JSON）
- ✅ 配置云端同步

---

## 快速开始

### 1. 连接设备

1. **点击"连接设备"按钮**
   - 首次连接会弹出浏览器设备选择对话框
   - 选择你的串口设备（如：COM3、/dev/ttyUSB0）

2. **授权设备访问**
   - 浏览器会请求串口访问权限
   - 点击"允许"授权

3. **配置串口参数**
   - 波特率：根据设备要求设置（常见：9600、115200）
   - 数据位：通常为 8
   - 校验位：通常为 none
   - 停止位：通常为 1
   - 流控制：通常为 none

4. **开始调试**
   - 设备发送的数据会自动显示在接收区
   - 在发送区输入数据，点击"发送"按钮

## 串口参数配置

### 基础参数

**波特率（Baud Rate）**
- 常用预设：9600, 19200, 38400, 57600, 115200, 230400, 460800, 921600
- 自定义输入：支持 300 - 4000000 范围
- 最近使用的波特率会优先显示

**数据位（Data Bits）**
- 可选：5, 6, 7, 8
- 默认：8

**校验位（Parity）**
- 可选：none, even, odd, mark, space
- 默认：none

**停止位（Stop Bits）**
- 可选：1, 1.5, 2
- 默认：1

**流控制（Flow Control）**
- 可选：none, hardware, software
- 默认：none

### 高级配置

**行结束符**
- 发送端：None, CR (\r), LF (\n), CRLF (\r\n)
- 接收端：None, CR, LF, CRLF, Auto（自动识别）

**字符编码**
- UTF-8：文本模式，支持中文和特殊字符
- HEX：十六进制模式，适合二进制协议

**接收缓冲区**
- 最大 100,000 行或 10 MB
- 超过限制自动清理最旧数据

## 数据收发

### 接收区

**数据显示**
- 实时显示设备发送的数据
- 支持自动换行或横向滚动
- 可选显示时间戳和行号
- 方向标识：接收数据显示绿色箭头 →

**关键字高亮**
- 配置关键字列表（最多 20 个）
- 支持正则表达式
- 预设常用关键字：
  - ERROR → 红色背景
  - WARN → 黄色背景
  - INFO → 蓝色背景
  - OK/SUCCESS → 绿色背景

**数据过滤**
- 文本搜索过滤（实时高亮匹配）
- 正则表达式过滤
- 方向过滤（仅接收/仅发送/全部）
- 时间范围过滤

### 发送区

**输入方式**
- 单行模式：回车发送，Shift+Enter 换行
- 多行模式：Enter 换行，Ctrl+Enter 发送
- 支持 UTF-8 文本输入
- 支持 HEX 输入（严格校验格式）

**发送历史**
- 记录最近 100 条发送内容
- 下拉列表显示（最多显示 20 项）
- 支持搜索历史
- 云同步（登录用户）

**发送方式**
- **立即发送**：点击或按 Enter
- **循环发送**：设置重复发送间隔，自动重复发送
  - 间隔时间：100ms / 500ms / 1s / 2s / 5s / 自定义
  - 发送次数：无限循环 / 指定次数
  - 随时停止重复发送
- **批量发送**：多指令队列按顺序发送
- **延时发送**：延迟 N 秒后发送

## 高级功能

### DTR/RTS 信号控制

**功能说明**
- DTR（Data Terminal Ready）：数据终端就绪信号
- RTS（Request To Send）：请求发送信号
- 常用于 Arduino 等设备的复位控制

**使用方法**
- 点击工具栏的"DTR"或"RTS"按钮
- 控制信号状态（高/低）
- 支持脉冲模式（短暂拉高后恢复）

### 循环发送

**使用场景**
- 定期查询设备状态
- 压力测试
- 心跳包发送

**配置示例**
```
指令: AT+STATUS?
间隔: 1s
次数: 无限循环（或指定次数：100）
[发送] [停止]
状态: 发送中 15 次
```

### 自动换行控制

**功能说明**
- 文本模式：默认开启自动换行（适合日志）
- HEX 模式：建议关闭换行（保持数据包完整性）
- 快捷键：Ctrl+W 切换

## 日志管理

### 清屏操作

- **立即清空**：删除所有数据
- **保留最后 N 行**：默认保留 100 行
- 确认对话框：避免误操作

### 导出功能

**导出格式**

1. **TXT 格式**（纯文本）
   ```
   [14:32:15.123] → [接收] Hello World
   [14:32:15.234] → [发送] AT+STATUS?
   [14:32:15.345] ← [接收] OK
   ```

2. **CSV 格式**
   ```csv
   时间戳,方向,数据
   2024-01-15 14:32:15.123,接收,Hello World
   2024-01-15 14:32:15.234,发送,AT+STATUS?
   ```

3. **JSON 格式**
   ```json
   {
     "exportTime": "2024-01-15T14:32:15Z",
     "config": {
       "baudRate": 115200,
       "dataBits": 8
     },
     "logs": [...]
   }
   ```

**导出选项**
- 数据方向：全部数据 / 仅接收 / 仅发送
- 时间范围：全部 / 最近 N 分钟 / 自定义范围
- 格式选项：包含时间戳、方向标识、配置信息

**快捷导出**
- `Ctrl+Shift+E` - 导出全部数据
- `Ctrl+Shift+R` - 导出接收数据
- `Ctrl+Shift+S` - 导出发送数据

## 常见问题

### Q: 无法看到串口设备怎么办？

**A:** 请检查：
1. 设备已正确连接并安装驱动
2. 设备未被其他程序占用
3. 浏览器已获得设备访问权限
4. 系统权限已正确配置（macOS 需要输入监控权限）

### Q: 连接设备后没有数据怎么办？

**A:** 请检查：
1. 串口参数是否正确（波特率、数据位等）
2. 设备是否正在发送数据
3. 编码格式是否匹配（文本/十六进制）
4. 流控制设置是否正确

### Q: 发送的数据出现乱码？

**A:** 请检查：
1. 编码格式是否匹配（UTF-8/HEX）
2. 串口参数是否正确
3. 设备端编码设置
