# 常见问题（FAQ）

> WebSerialTool 常见问题解答

---

## 浏览器兼容性问题

### Q: 为什么我的浏览器没有"连接设备"按钮？

**A:** Web Serial API 目前只支持 Chrome 89+ 和 Edge 89+。如果你使用的是 Firefox 或 Safari，请切换到 Chrome 或 Edge 浏览器。

### Q: 为什么提示需要在 HTTPS 环境下使用？

**A:** Web Serial API 是浏览器安全特性，必须在 HTTPS 或 localhost 环境下才能使用。生产环境会自动使用 HTTPS，本地开发可以使用 `http://localhost`。

---

## 设备连接问题

### Q: 无法看到串口设备怎么办？

**A:** 请检查以下几点：
1. 设备已正确连接并安装驱动
2. 设备未被其他程序占用
3. 浏览器已获得设备访问权限
4. 系统权限已正确配置（macOS 需要输入监控权限）

### Q: 连接设备后没有数据怎么办？

**A:** 请检查：
1. 串口参数是否正确（波特率、数据位等）
2. 设备是否正在发送数据
3. 编码格式是否匹配（文本/十六进制）
4. 流控制设置是否正确

---

## 权限问题

### Q: macOS 系统提示需要权限怎么办？

**A:** macOS 系统需要授权浏览器访问串口设备：
1. 打开"系统设置" → "隐私与安全性"
2. 找到"输入监控"或"USB"权限
3. 添加浏览器（Chrome 或 Edge）到允许列表
4. 重新连接设备

### Q: Linux 系统提示权限不足怎么办？

**A:** Linux 系统需要将用户添加到 `dialout` 组：
```bash
sudo usermod -a -G dialout $USER
```
然后重新登录或重启系统。

## 远程协作问题

### Q: 邀请码无效怎么办？

**A:** 请检查：
1. 邀请码是否正确（6位数字）
2. 会话是否已过期或结束
3. 网络连接是否正常
4. 信令服务器是否可访问

### Q: 远程协作时数据延迟高怎么办？

**A:** 数据延迟主要受网络影响：
1. 检查网络连接质量
2. 确保双方网络稳定
3. 如果延迟过高，考虑使用本地调试

---

## 配置同步问题

### Q: 配置没有同步到其他设备？

**A:** 请确保：
1. 已登录账户
2. 配置已保存到云端
3. 其他设备使用相同账户登录
4. 网络连接正常

### Q: 如何清除本地配置？

**A:** 可以在设置中清除本地数据，或使用浏览器的清除数据功能。云端配置不会受影响。

---

## 其他问题

### Q: 发送的数据出现乱码？

**A:** 请检查：
1. 编码格式是否匹配（UTF-8/HEX）
2. 串口参数是否正确
3. 设备端编码设置

### Q: 如何导出日志？

**A:** 点击工具栏的"导出"按钮，选择格式（TXT 或 CSV），即可下载日志文件。

### Q: 支持哪些操作系统？

**A:** WebSerialTool 支持所有支持 Chrome/Edge 的操作系统：
- Windows 10+
- macOS 11+
- Linux（主流发行版）
